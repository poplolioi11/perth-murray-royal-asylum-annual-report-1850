# 柏斯詹姆斯・莫瑞皇家精神病院第 23 年報（1850） / Twenty-third Annual Report of the Directors of James Murray’s Royal Asylum for Lunatics — Transcription Dataset

蘇格蘭柏斯詹姆斯・莫瑞皇家精神病院第 23 年報包含董事報告與醫師 William Malcom 的附錄。原刊記下貧窮法送院、出院後再入院、高齡住院者的日常照護，以及個別轉送與入院結果。八張統計表可定位到原頁。

The June 1850 report of James Murray’s Royal Asylum in Perth includes the directors’ report and a medical appendix by William Malcom. It documents admissions under the Poor Law, readmissions, recreation, care of older residents, and two individual outcomes after admission.

## Source and scope

Wellcome Collection, Medical Heritage Library, b30317071, Source frames 1–16. Original publication: Perth, C. G. Sidey, 1850. All sixteen source images are inventoried, including the title leaf, the medical appendix and eight numbered tables. Two marked gaps occur on pages 12 and 13.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
## Transcription and review

AI-assisted reading used fixed source scans. Published text preserves printed spellings and historical terminology. Spacing may be normalized. A square (□) indicates an unresolved character. See the notes for editorial omissions and uncertain readings.

Version 0.2.0. This dataset has no measured error rate or expert proofreading.
